# Connect ChatGPT

**Not supported yet.** ChatGPT's custom connectors run in the cloud and sign in with OAuth, the same needs as [Claude on the web](claude-web.md): a fixed public address, a sign-in service, and the brain up whenever you use it. pocketBrain hasn't been tested with ChatGPT's connectors, so this page doesn't promise it works even with all three in place.

What works today: any of the [apps on your own computer](../connect.md) share the same brain, and what they save is there for every assistant you connect later.
